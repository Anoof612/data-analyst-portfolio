PROJECT 03 · POWER BI

Cricket Performance Analytics

An interactive Power BI dashboard analyzing player and tournament performance using ICC T20 World Cup 2022 records. The dashboard provides analytical views for batting, bowling, all-round performance, and player selection.

Project Overview

This project uses Power BI to analyze player performance during the ICC T20 World Cup 2022. It evaluates batting, bowling, and all-rounder statistics using interactive dashboards and performance indicators.

Key Analysis

  • KPI overview
  • Power hitters analysis
  • Anchors analysis
  • Finishers analysis
  • All-rounder analysis
  • Bowling performance analysis
  • Final XI player selection
  • Player details and match-wise performance
  • Interactive player tooltips
