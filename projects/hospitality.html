PROJECT 02 · POWER BI

Hospitality Performance Analytics

An interactive Power BI dashboard for analyzing hotel and hospitality performance across properties and booking platforms. The dashboard focuses on key hospitality performance metrics and property-level analysis.

Project Overview

This project analyzes hotel performance through interactive Power BI dashboards. It explores revenue, room occupancy, pricing, booking platforms, and property performance to support data-driven hospitality business decisions.

Key Analysis

  • Revenue and RevPAR performance
  • Average Daily Rate (ADR)
  • Occupancy percentage
  • Realisation percentage
  • Daily Sellable Room Nights (DSRN)
  • Week-over-week performance
  • Occupancy by property category
  • Booking-platform performance
  • Property-level performance
